# Haftalık Plan

Antrenman programının PDF'ini yükle; site günleri ve hareketleri okuyup düzenlenebilir, haftalık takip edilebilir bir plana çevirir. Gram bazlı makro takibi (protein / karbonhidrat / yağ, kalori 4/4/9) dahil.

- Ücretsiz, hesap yok, sunucu yok: PDF tarayıcıda okunur (pdf.js), veriler cihazın tarayıcısında saklanır.
- Her pazartesi yeni hafta başlar; geçmiş haftalar grafikte kalır.
- Yedek indir / yükle ile veriler başka cihaza taşınabilir.

Site: https://xyroth-mrt.github.io/haftalik-plan/
